# AI 排班 Skill

根据上月值班表和本月人员安排，生成客服售前、售后月度早晚班排班表。Skill 会在原工作簿中新增目标月份的工作表，并尽量沿用现有模板。

## 适用场景

- 按售前、售后两组分别安排早班和晚班。
- 根据上月排班处理正常休息补偿、月末连续工作和班次衔接。
- 纳入指定休息与请假，并检查每天的人员覆盖。
- 在 Excel 模板中新增月度排班表及公式汇总。

在 Codex 中可以直接描述排班需求，也可以显式调用 `$ai-duty-roster`。

## 提供的信息

请提供目标年月、上月排班工作簿路径、历史工作表名称，以及本月售前和售后人员名单。指定休息和请假按员工及日期列出；没有相应安排时可以省略。

```text
目标月份：2026年11月
上月排班表：C:\\排班资料\\2026年10月份值班表.xlsx
历史Sheet：10月值班表

售前：
张三
李四

售后：
王五
赵六

指定休息：
张三：2、3、4

请假：
李四：10～15
```

## 排班规则

- 售前、售后每天的早班和晚班分别安排 3～4 人；每人每天最多一个班次。
- 指定休息计入正常休息额度；请假不计入正常休息，也不能排班。
- 普通情况下每人正常休息 3～6 天、上班 24～27 天。有请假时，上班天数允许低于 24 天，但仍须按自然日、正常休息和请假准确对账，且每天各班人数要求不变。
- 晚班后次日不能接早班，至少间隔一个不上班日；跨月检查同样适用。
- 连续工作尽量接近 7 天一休，不能超过 10 天。
- 用户提供的本月人员名单优先于历史名单。固定条件导致硬规则无法同时满足时，会先说明具体日期和缺口，不强行凑表。

完整规则见 [`references/排班规则.md`](references/排班规则.md)。

## 工作簿处理与输出

- 以历史工作簿为模板新增“`M月值班表`”，保留原有工作表。
- 写入前核对目标月份的日历周块和模板空间；排班先验证，再写入工作簿。
- 汇总区分别列出指定休息、请假和排班统计，优先使用公式关联排班明细。
- 输出前核对每日人数、休假、班次衔接、连续工作、月度统计和公式结果。
- 模板中的线下区域目前只保留，不参与自动排班。
