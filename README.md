# ai-duty-roster — AI 排班 Skill

用于生成客服 **售前 / 售后** 两组人员的月度值班表：读取上月排班与本月条件，做可行性检查，求解满足全部硬约束的排班，并在原工作簿中新增「M月值班表」Sheet。

## 能力

- **硬约束**：每天售前、售后早班各 3~4 人、晚班各 3~4 人；每人每天仅一个状态（早 / 晚 / 正常休息 / 请假）
- **晚班转早班限制**：晚班次日不得排早班，含跨月校验
- **连续工作**：跨月累计，目标约 7 天一休，超过 10 天视为不可接受（停止排班并反馈）
- **跨月补偿**：按上月实际休息与基础休息的差额，在本月倾向多休 / 少休，且不突破 3~6 天边界
- **两类"不上班"**：指定休息（计入正常休息额度、参与跨月补偿）与请假（不计入额度、不放宽每日班次人数）
- **可行性检查**：条件冲突时列出冲突员工 / 日期 / 规则与最小放宽方案，不自行凑表
- **输出**：沿用上月版式复制新 Sheet，底部含指定休息、请假休息、排班汇总三区，汇总用 Excel 公式联动明细

## 目录结构

```
SKILL.md                  主流程：输入要求、执行步骤、优化顺序、验证清单、本地写入（editor_sdk）
references/排班规则.md     正式业务规则：每日人数、休息目标、跨月补偿、连续工作、班次切换、验收清单
scripts/roster_nov.py     历史解析 → 跨月状态 → 休息预算贪心生成 → 全量校验（示例脚本，员工姓名已脱敏为占位符）
scripts/build_writes.py   把排班结果转成 editor_sdk 的批量写值参数与清空区坐标
```

## 使用

作为 WorkBuddy / Claude Skill 使用时，把本仓库放入技能目录：

```bash
git clone <this-repo> ~/.workbuddy/skills/ai-duty-roster
```

然后在会话中提供以下输入：

```
目标月份：2026年11月
上月排班表：C:\...\2026年10月份值班表.xlsx
历史Sheet：10月值班表

售前：
（名单）

售后：
（名单）

指定休息：
（员工：日期）

请假：
（员工：日期）
```

## 说明

- `scripts/` 中的脚本是**示例实现**：员工姓名、月份条件均已脱敏为占位符（员工A~员工R），实际使用时按现场的名单与历史数据调整
- 本地 `xlsx` 写入走 editor_sdk 通道（`sheet_copy_sheet` / `sheet_insert_dimension` / `sheet_set_range_value` / `save_file`），相关坑位见 `SKILL.md` 的「本地写入」一节
- 排班结果属内部管理信息，仓库内的数据均为占位示例，不含真实人员信息
